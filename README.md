# Employee Analytics Dashboard
## About the Project
I created this project using Power BI to explore employee data and understand different HR activities. 
It includes interactive dashboards covering employee details, attrition, performance, recruitment, attendance and training.

## Dashboard Pages
1. HR Overview
2. Attrition Analysis
3. Performance Analysis
4. Learning & Development
5. Recruitment Analytics
6. Attendance Analysis
7. Workforce Insights

- ## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

- ## Project Files
- Raw Dataset – Original employee data used for analysis.
- Power BI Dashboard – Completed `.pbix` file.
- Dashboard Screenshots – Screenshots of all 7 dashboard pages.

- ## Key Learnings
- Learned to clean and transform data using Power Query.
- Practiced creating DAX measures.
- Built interactive dashboards using different visuals.
- Improved my understanding of employee and HR data.
